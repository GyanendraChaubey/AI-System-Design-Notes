An AI-native recommendation system covering two-tower retrieval, real-time feature serving, LLM-based reranking and explanation generation, and the feedback loops that keep recommendations fresh as user preferences and item catalogs evolve.

## What This Case Study Will Cover

- Two-tower model architecture for scalable candidate retrieval at item-catalog scale
- Real-time feature store design: user context, session signals, and item embeddings
- LLM-based reranking and personalized explanation generation
- Offline batch candidate pre-computation vs. real-time retrieval tradeoffs
- Feedback loop design: implicit signals, A/B testing, and avoiding filter-bubble drift
