# Short-Term vs Long-Term Memory

!!! info "📋 Planned"
    This page is scaffolded but not yet written at full depth. The engineering tradeoff between keeping everything in the active context window (short-term) versus persisting and later retrieving facts (long-term), and how production systems blend both.

## What This Chapter Will Cover

- Short-term: cheap, fast, bounded by context window
- Long-term: unbounded, retrieval-latency cost, consolidation needed
- Consolidation: promoting short-term to long-term memory
- Failure modes: premature forgetting, stale long-term facts
